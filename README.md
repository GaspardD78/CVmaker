# CVmaker — ResumeForge

Application de gestion de CV et de suivi de candidatures, disponible sur **Windows / macOS / Linux** et **Android**.

Construite avec [Tauri 2](https://tauri.app), React 19 et TypeScript. Toutes les données sont stockées localement dans une base SQLite — aucun compte, aucun serveur requis. Une synchronisation optionnelle via Google Drive est disponible pour partager les données entre appareils.
